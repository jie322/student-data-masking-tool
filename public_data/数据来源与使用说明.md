# 已下载的公开数据

本目录保存公开下载件、中文导入表和处理对照。资料通过 curl 下载，单文件不超过 20 MB，总量不超过 200 MB。原始下载件、整理后的表格、脱敏结果均计入本目录大小。

## 文件位置

- 效果对照：<http://127.0.0.1:8000/public_data/脱敏效果对照.html>
- 中文导入文件：`imports/`
- 原始下载件：`originals/`
- 实际脱敏结果：`outputs/`
- 来源、许可及校验信息：`sources.json`

学校联系方式是机构主动公开的办公资料，包含负责人姓名，适合观察姓名、电话、邮箱和地址的遮盖效果。后三类学生数据来自真实教育记录，但发布者已经做过匿名化，不含完整手机号、身份证或原始姓名。两类来源的含义在本目录中保留，不拼接或新增身份字段。

## 脱敏配置

导入 `imports/01_香港学校公开联系方式.csv`，按下表调整字段类型。该表保留八列公开资料。配置后先点击“预览脱敏效果”，再进行完整处理。表头别名只自动匹配其中“邮箱”和“地址”，其他需要处理的列按下表手动配置。

| 字段 | 类型 | 方式 | 保留位数 |
| --- | --- | --- | --- |
| 学校名称 | 学号 / 身份标识 | 全部隐藏 | 无 |
| 校长姓名 | 姓名 | 部分遮盖 | 前 1、后 0 |
| 办公电话 | 敏感文本 | 部分遮盖 | 前 2、后 2 |
| 邮箱 | 邮箱 | 部分遮盖 | 前 1，关闭保留域名 |
| 地址 | 地址 | 全部隐藏 | 无 |
| 传真号码 | 敏感文本 | 全部隐藏 | 无 |
| 地区、学校网址 | 普通字段 | 保留原值 | 无 |

学校名称可能含有人名，全部隐藏可以防止该列带出已识别姓名。香港及新加坡办公电话按来源格式保留，采用敏感文本遮盖；中国大陆手机号的 +86 校验规则继续用于项目中的手机号字段。

`outputs/01_香港学校公开联系方式_已脱敏.csv` 和 `outputs/02_新加坡学校公开联系方式_已脱敏.csv` 已由当前项目的处理引擎实际生成，两份结果均通过残留检查。`脱敏前后对照.csv` 保留前几条公开记录的原始值与处理结果，供核对。

`联系方式规则.json` 保存同一配置供脚本复现，页面目前不提供 JSON 规则导入按钮。两份学校联系方式表按该配置处理后，结果与保存的脱敏表格一致，敏感残留为 0。

四份已匿名化的学生数据可以导入查看，但当前表头不会触发默认敏感规则，全部保留时程序会提示至少配置一条处理规则。需要进行字段处理时，可按实际分享范围将学校代码、课程代码等列设为身份标识并遮盖或删除；这些表本身不含完整电话、身份证或原始姓名，不能用于验证这些直接身份字段的遮盖效果。

## 原件与转换记录

- 香港原件为官方完整 CSV，保留 120 个字段。导入版只选取上述 8 列。
- 新加坡原件为官方 API 的完整 JSON 响应，已核对返回 337 条与接口声明的总数一致。导入版只选取 8 列，`na` 等缺失占位符转为空值。
- UCI 原始压缩包均保留。中学生数据包包含内层 ZIP，仅按固定文件名读取数学、葡语 CSV 和数据字典；大学生数据的原始 CSV 也已保留。导入版本把分号改为逗号、表头改为中文，数据值不变。
- OULAD 原件经校验与来源记录一致，包含 25,818 行数据，来源清单记录实际行数。导入版只翻译表头，数字编码不改为姓名或电话号码。
- 中文文件采用 UTF-8 BOM，方便 Excel 直接识别。没有添加身份证号或联系信息来填充已匿名化的学生记录。

UCI 两组数据及 OULAD 子集采用 CC BY 4.0，引用对应发布页和作者。新加坡数据遵循 [Singapore Open Data Licence](https://data.gov.sg/open-data-licence)。香港数据按 DATA.GOV.HK 使用条款及家庭与学校合作事宜委员会的知识产权声明使用，来源信息保留在 `sources.json`。
