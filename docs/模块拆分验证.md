# 模块验证

## 验证范围

验证内容包括页面入口、后台通信、Python 表格处理和桌面运行模块。模块调整后保持导入、规则配置、预览和导出接口一致。

| 入口 | 实现位置 | 主要职责 |
| --- | --- | --- |
| `js/main.js` | `js/ui/`、`js/features/`、`js/services/` | 页面显示、操作流程和后台通信 |
| `js/worker.js` | `js/worker/` | 加载运行库并分发处理任务 |
| `py/student.py` | `py/student_tool/` | 读取表格、字段处理、异常检查和文件写出 |
| `desktop.py` | `desktop_app/` | 窗口管理、本地服务和文件保存 |

## 验证方法

在项目根目录执行全套测试：

```powershell
.venv\Scripts\python.exe -m pytest tests -q
```

自动化测试覆盖字段规则、异常策略、敏感残留、源文件保留和结果导出。浏览器与桌面环境分别验证文件导入、样本预览、批量处理及保存流程。
