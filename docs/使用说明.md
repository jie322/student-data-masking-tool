# 使用说明

## 1. 启动与导入

桌面方式运行交付目录中的 `学生信息脱敏工具.exe`。浏览器方式在项目目录执行 `python run_local.py`，通过 <http://127.0.0.1:8000/index.html> 访问。页面显示“引擎已就绪”后可导入文件。

| 项目 | 支持范围 |
| --- | --- |
| 文件格式 | CSV、TSV、Excel `.xlsx`；`.xls` 需另存为 `.xlsx` |
| 文件大小 | 单文件不超过 25 MB |
| 数据行数 | 每份文件最多 10 万行，多工作表合计，表头不计入 |
| 文本编码 | UTF-8、UTF-8 BOM；解码失败时尝试 GB18030 |
| 表头 | 第一行作为列名，不允许空列名或重复列名 |
| 多文件 | 一次可选择多份文件；内容完全相同的文件只导入一次 |
| Excel 工作表 | 每张表分别处理，隐藏工作表同样参与 |

导入后，页面列出文件行数、工作表数量和大小。原始样本需要手动展开，每张表最多显示前 5 行。读取失败的文件应先移除或整理后重新导入。

身份证、手机号和学号宜按文本存储。若源 Excel 已把长号码转成不完整数值，工具无法恢复丢失的位数。

## 2. 字段推荐与配置

字段类型根据表头别名推荐。例如“手机号”“手机号码”“联系电话”匹配为手机号；匹配前会去除两端空白、转为小写并去掉普通空格。程序不根据整列内容推断字段含义，也不采用大模型识别。

未匹配的列按普通字段保留。导入公开联系方式时，“校长姓名”“办公电话”等表头需要手动选择类型；“学校网址”应保留为普通字段。具体配置见 [公开数据说明](../public_data/数据来源与使用说明.md)。

| 字段类型 | 推荐处理 | 默认保留位数 | 说明 |
| --- | --- | --- | --- |
| 手机号 | 部分遮盖 | 前 3、后 4 | 接受规范化后的大陆 11 位号码，输出统一加 `+86` |
| 邮箱 | 部分遮盖 | 账户名前 1 位 | 默认隐藏域名，可勾选保留域名；短账户名至少隐藏一个字符 |
| 身份证号 | 部分遮盖 | 前 3、后 2 | 检查 18 位结构、出生日期和校验位，末位可为 X |
| 姓名 | 部分遮盖 | 前 1、后 0 | 单字姓名显示为 `*` |
| 学号／身份标识 | 部分遮盖 | 前 4、后 0 | 对应学号、学生编号、校园卡号等已登记别名 |
| 地址 | 全部隐藏 | 不使用 | 结果为 `〔已隐藏〕` |
| 敏感文本 | 全部隐藏 | 不使用 | 可手动改为部分遮盖 |
| 普通字段 | 保留原值 | 不使用 | 成绩等字段可按实际需要保留 |

同名列共用一条规则；修改一处后，本批次所有同名列均采用该规则。默认对姓名、学号和校园卡号等已推荐为姓名或身份标识的列启用必填校验。

表头“身份标识”的现有别名对应身份证类型；如果该列实际存放学号或其他编号，应手动改为“学号／身份标识”。字段类型以表内实际内容为准。

四种处理方式分别为保留原值、部分遮盖、全部隐藏、删除此列。位数只能填写 0 至 6 的整数，且不同字段有保留总位数限制。普通字段需要先选择敏感类型，才能使用部分遮盖。全部列均保留或全部列均删除时，程序会要求重新配置。

目前页面通过控件配置规则，没有 JSON 规则文件导入按钮。`public_data/联系方式规则.json` 用于查看或在 Python 脚本中复现同一配置。

## 3. 样本预览与完整处理

点击“预览脱敏效果”后，各表前 10 行按当前规则处理并直接展开。预览不创建结果包或报告下载文件，也不修改源文件。

确认样式后点击“开始批量脱敏”。程序重新读取源文件副本，处理全部行并检查残留。正式结果默认收起，可点击各表的“预览前 10 行”单独查看，再次点击收起。

规则、异常策略或文件列表发生变化时，旧预览与下载地址会失效。重新预览只说明样本处理情况，仍需完整处理才能导出。

## 4. 异常行处理

| 策略 | 处理方式 |
| --- | --- |
| 隐藏异常字段，保留其余内容 | 格式错误值隐藏，缺失值保留为空，其余列继续处理；重复标识在报告中记录 |
| 跳过整行 | 发现格式、缺失或重复标识等异常时，整行不进入导出结果 |
| 停止导出 | 完成检查并返回位置记录，有异常时阻止本批次的表格下载 |

列数与表头不一致的行在三种策略下都隔离。公式文本转义和已有脱敏值的重新处理单独记录，不计入上述异常行数。

重复身份标识在同一工作表内检查。报告沿用原表行列位置，删除某列后也不改变问题的原始定位。

## 5. 结果、报告与保存

检查通过后，结果包包含编号命名的脱敏表格和 `处理报告.json`，不附原始文件。CSV、TSV 和 Excel 保持对应格式；Excel 重新创建工作簿，不复制源批注、外部链接和原表名，工作表统一命名为“数据表1”等。

报告记录文件编号、统计、异常位置、固定原因及所用规则参数，不记录源文件名、敏感列名和单元格原文。浏览器直接下载；桌面程序弹出保存对话框，由使用者选择位置。

完整处理后检出敏感残留，或停止策略遇到异常时，整个批次的表格下载被阻止，仍可保存处理报告。读取失败、规则不合法等导致处理未完成时，不生成结果包或报告。

“保留行数”表示处理结果中的候选行数；如果导出已被阻止，显示这一计数并不表示文件已写出。异常行数与异常记录数也不同，一行可能有多个问题。

## 6. 检查范围

残留检查包括表头和全部输出行，匹配完整手机号、邮箱、15/18 位身份号码，以及同一文件中已标记敏感类型的原文。原文检查跨列、跨工作表进行，不建立跨文件的姓名或学号对照。

15 位身份号码属于残留扫描对象，不能作为身份证字段的有效输入；身份证字段只接受 18 位。校验结构和日期不代表核实真实身份。

公式形式的文字按普通文本导出。以 `+86` 开头的规范手机号和普通负数按专门条件保留，避免误转义正常数据。

结果包为普通 ZIP，没有密码加密。部分遮盖保留了部分内容；未登记的敏感字段和多列组合形成的身份线索，应结合接收范围自行核对。

## 7. 异常提示与处理

| 现象 | 处理方法 |
| --- | --- |
| 引擎一直未就绪 | 确认通过本地地址访问，并检查 `vendor/` 是否完整 |
| 提示 IDM 拦截 ZIP | 关闭当前浏览器的 IDM 集成扩展后刷新，或使用桌面程序 |
| 提示至少配置一条脱敏规则 | 检查是否所有列都处于保留状态，按需要选择实际处理的列 |
| 境外办公电话显示格式异常 | 这类号码按敏感文本配置，不套用大陆手机号规则 |
| 样本检查通过，整表导出被阻止 | 查看完整报告，问题可能位于样本以外的数据行 |
| 源码修改未同步至 EXE | 从当前源码重新打包；已有 EXE 不会自动读取更新后的模块 |

运行和构建方法见 [开发与打包](开发与打包.md)，现有表格说明见 [学生信息表说明](../sample_data/使用说明.md)。
